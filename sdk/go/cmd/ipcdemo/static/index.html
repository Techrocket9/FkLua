fkipc demo — two mods, one game

connecting…

Both mods share the game's single --enable-lua-udp socket, so every datagram below is delivered to both of them; each guest keeps its own conversation by refusing frames whose source port is not its configured peer's. Slider moves are throttled to ten a second and go out as correlated RPC — the value shown beside each slider is the guest's ack, and the readouts below it are a separate telemetry stream sampled from the running game.
